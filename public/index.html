Cara Mudah Mengambil & Memasang Cookie

SocialHub menggunakan sesi browser asli yang diekspor dalam format JSON. Anda tidak perlu mendaftar API developer berbayar atau akun bisnis resmi.

1 Pasang Ekstensi Cookie-Editor di Browser Anda:
Download gratis melalui Chrome Web Store atau Firefox Add-ons (cari: Cookie-Editor).
2 Buka Akun Sosial Media yang Ingin Dihubungkan:
Buka tab baru, kunjungi situs platform, dan pastikan Anda sudah login ke profil Anda:

3 Ekspor sebagai JSON:
Di tab platform yang sudah login, klik ikon ekstensi Cookie-Editor di pojok kanan atas browser ➔ klik tombol Export ➔ pilih Export as JSON (otomatis tersalin ke clipboard).
4 Tempelkan Langsung di Dashboard ini:
Pada panel Manajemen Cookie di sisi kanan dashboard, klik tombol + Pasang / Update pada platform yang sesuai, lalu paste isinya dan klik Simpan Cookie. Selesai!

Pemisahan Mode Posting: Teks vs Media Visual

Setiap platform memiliki aturan arsitektur upload yang berbeda:

📝 Mode Teks & Status
Threads, X/Twitter, FB Pribadi & Page, LinkedIn
  • Mendukung posting status teks murni (opini, thread, quote).
  • Mendukung lampiran link / tautan dengan auto-preview kaya (Open Graph).
  • Lampiran gambar / video bersifat opsional.
📸 Mode Media Visual
Instagram, TikTok, YouTube Studio
  • WAJIB menyertakan file foto atau video. Web uploader platform ini tidak mengizinkan posting teks saja di feed.
  • Instagram & TikTok: Mendukung format Foto (JPG, PNG) & Video (MP4, WebM).
  • YouTube Studio: Mendukung format Video (.MP4, .MOV, .WebM).
  • Dilengkapi opsi Cross-Post untuk sekaligus membagikan media Anda ke Threads, X, Facebook, dan LinkedIn secara serentak!

Shortcut Desktop & Perintah CLI Cepat

Selain dashboard web, Anda juga dapat menjalankan proses publikasi langsung lewat file launcher Windows:

🚀 1. Launcher Windows (.bat):
  • Buka Dashboard.bat: Menjalankan server lokal di latar belakang dan langsung membuka browser ke http://localhost:3456.
  • POSTING.bat: Prompt interaktif di terminal untuk posting teks/status cepat ke Threads, Twitter, Facebook, dan LinkedIn.
  • POSTING_MEDIA.bat: Prompt interaktif untuk posting foto/video ke Instagram, TikTok, YouTube, dll.
💻 2. Perintah CLI (Command-Line):

Buka terminal di folder project lalu gunakan sintaks berikut:

# Posting teks status serentak ke platform teks: node src/cli.js --text "Halo semua! Update terbaru hari ini." # Posting foto / video ke Instagram & TikTok: node src/cli.js --text "Pemandangan indah #travel" --media "C:\path\foto.jpg" --platforms instagram,tiktok # Upload video ke YouTube Studio & cross-post ke LinkedIn: node src/cli.js --text "Tutorial Koding Modern" --media "C:\path\video.mp4" --platforms youtube,linkedin # Menampilkan browser saat proses berlangsung (mode non-headless untuk debug): node src/cli.js --text "Testing browser" --visible

💻 Fitur Khusus: AI Persona & Visual Anak IT

SocialHub dilengkapi preset AI khusus yang memahami bahasa, kultur, meme, dan realita dunia software engineering:

💻 Persona "Anak IT / Programmer (Relatable & Techy)":

Membuat copywriting yang sangat relate dengan kehidupan developer (suka duka debugging, deploy hari Jumat, clean code, coffee habits, error 500, git commit, framework war) dengan gaya santai dan cerdas.

🖥️ Persona "Tech Lead & Software Engineering":

Sangat cocok untuk postingan profesional di LinkedIn: membahas software architecture, scalability, microservices, system design, dan best practice rekayasa perangkat lunak.

🎨 Visual Meja Koding (Developer Workspace Aesthetic):

AI Generator Gambar (Flux) dapat menghasilkan visual setup meja ngoding modern (dual monitor vertikal, mechanical keyboard RGB, IDE dark mode, kopi, ambient lighting) serta visual Isometric 3D Room dan Pixel Art Retro Tech.

⚡ Chip Ide Cepat 1-Klik:

Cukup klik salah satu chip topik di dalam modal (seperti Clean Code, Deploy Jumat, Ngoding & Kopi, Impostor Syndrome) untuk langsung mengisi prompt secara instan tanpa perlu mengetik panjang.

Tips Praktis & Solusi Kendala (Troubleshooting)

❓ Sesi / Cookie Berakhir (Expired):

Jika status postingan gagal dengan pesan sesi login kedaluwarsa, cukup buka browser biasa, login ulang ke situs akun Anda, ekspor JSON cookie baru dengan Cookie-Editor, lalu klik tombol Update di dashboard.

📄 Posting ke Facebook Page (Halaman Bisnis):

Cookie untuk Facebook Page menggunakan file yang sama dengan Facebook Pribadi (facebook.json). Pastikan akun Facebook pribadi Anda berstatus Admin di Halaman Bisnis tersebut agar Playwright dapat melakukan switch profil secara mulus.

💼 LinkedIn Auto-Sign-In:

Saat pertama kali dibuka, LinkedIn sering memunculkan animasi "We're signing you in" selama beberapa detik. Sistem SocialHub telah dilengkapi penanganan otomatis untuk menunggu proses transisi ini hingga mendarat di feed.

📁 Batasan Ukuran File:

Ukuran file media maksimal yang didukung oleh dashboard adalah 100 MB. Untuk video berdurasi panjang di YouTube Studio atau TikTok, disarankan menggunakan format kompresi MP4 H.264 standar.
